EduControl

Tecnologia para melhorar o ambiente escolar

Uma proposta de sistema para auxiliar no controle do uso de smartphones durante as aulas.

Sobre o projeto

O EduControl é uma proposta desenvolvida para auxiliar no controle do uso de dispositivos móveis dentro da escola.

A ideia é permitir que os smartphones sejam utilizados de forma mais organizada, principalmente durante as aulas, sem impedir seu uso quando houver uma finalidade pedagógica.

Principais funcionalidades

📱 Controle de uso

Auxiliar no controle do uso dos smartphones durante os horários de aula.

📝 Registro

Permitir o registro de ocorrências relacionadas ao uso dos dispositivos.

📊 Relatórios

Organizar informações para facilitar o acompanhamento do uso dos aparelhos.

Como funcionaria?

1

Configuração

A escola define os horários e as regras para utilização dos dispositivos.

2

Acompanhamento

Professores e responsáveis podem acompanhar as informações registradas.

3

Análise

Os registros podem ajudar a identificar situações que precisam de atenção.

Conclusão

Espera-se que o EduControl contribua para um uso mais consciente e organizado dos smartphones no ambiente escolar.

A proposta busca ajudar professores e alunos, diminuindo possíveis distrações durante as aulas e mantendo a tecnologia disponível quando ela possuir finalidade pedagógica.
